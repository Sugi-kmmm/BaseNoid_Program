# BaseNoid 操作方法

BaseNoid サンプルプログラム（[src/main.cpp](../src/main.cpp)）の操作方法をまとめたものです．
ボタン名は PS4 コントローラ（DUALSHOCK 4）の表記です．

## 1. 起動

1. 電源を入れると LED が青く点灯し，シリアルモニタ（115200 bps）に案内が表示されます．
2. 3 秒間，シリアルからの入力を待ちます．
   - `s` : 設定モードに入る（[5. 設定モード](#5-設定モード)）
   - `c` : 待ち時間を打ち切ってすぐに起動する
   - 何も入力しない : 3 秒後に自動で起動する
3. サーボのトルクが入り，直立姿勢になります．LED が緑になれば操作できます．

> 起動時にサーボが直立姿勢へ動きます．手や物を挟まないよう，ロボットを支えた状態で電源を入れてください．

コントローラは Bluetooth で接続します．ペアリング情報は起動のたびに消去されるため，電源を入れるごとに接続し直してください．
コントローラ側に登録する BaseNoid の Bluetooth MAC アドレスは，設定モードの `3` で確認できます．

## 2. LED 表示

| LED の色 | 状態 |
| --- | --- |
| 青 | トルク OFF（脱力） |
| 緑 | トルク ON（操作可能） |
| 黄 | 設定モード |
| 紫 | 対応していないコントローラが接続された |
| 赤の点滅 | バッテリー電圧が範囲外．動作を停止しているので，バッテリーを確認して電源を入れ直す |

## 3. 姿勢と操作の関係

BaseNoid には 2 つの姿勢があり，**○ ボタン**で切り替えます．姿勢によって使える操作が変わります．

| 姿勢 | 説明 |
| --- | --- |
| 直立姿勢 | 起動直後の姿勢．ひざを伸ばして立っている |
| 歩行準備姿勢 | ひざを曲げて腰を落とした姿勢．歩行はこの姿勢でのみ可能 |

## 4. コントローラ操作

### 常に使える操作

| 操作 | 動作 |
| --- | --- |
| PS ボタン | トルクの ON / OFF を切り替える．ON にすると直立姿勢に戻る |
| ○ | 直立姿勢 ⇔ 歩行準備姿勢を切り替える |
| △ | パンチ |
| R1 | 右手を振る |
| L1 または 十字キー左 | 左手を振る |
| R2 | バンザイ |
| L2 または 十字キー右 | ツッコミ |

- 上半身のモーション（△，L1 / R1，L2 / R2）は，ボタンを押した瞬間に 1 回だけ再生されます．押しっぱなしにしても繰り返しません．
- L2 / R2 は半分以上押し込むと反応します．
- 十字キー左 / 右は，L1 / L2 が正常に動作しないコントローラのための代替です．
- PS ボタンでトルクを OFF にするとロボットは脱力します．倒れないよう支えてから押してください．

### 歩行準備姿勢での操作

| 操作 | 動作 |
| --- | --- |
| 左スティック 上 / 下 | 前進 / 後退 |
| 左スティック 左 / 右 | 左旋回 / 右旋回 |
| 十字キー下 | しゃがむ |
| 十字キー上 | 立ち上がる |
| × | サーボの制御遅れを測定する（調整用） |

- スティックを倒す量で歩幅・旋回量が変わります．前後と左右を同時に倒すと，旋回しながら歩きます．
- スティックを中立に戻すと，足をそろえて停止します．
- 歩行中は，スティックと PS ボタン以外の操作を受け付けません．
- コントローラの接続が切れると，歩行は自動で停止します．

### 直立姿勢での操作

| 操作 | 動作 |
| --- | --- |
| □ | ランダムモーションの開始 / 停止 |

- □ を押すと，サンプルモーションをランダムに再生し続けます．もう一度 □ を押すとその場で停止し，正面を向き直します．
- コントローラの接続が切れた場合も停止します．

### トルク OFF 時の操作

| 操作 | 動作 |
| --- | --- |
| OPTIONS | 設定モードに入る |

## 5. 設定モード

シリアルモニタから数字を入力して項目を選びます．設定モード中は LED が黄色になります．

| 入力 | 項目 |
| --- | --- |
| `1` | バッテリー電圧の校正．テスターで測った実際の電圧（例 : `7.40`）を入力する |
| `2` | 全サーボの角度を表示し続ける．`c` で終了 |
| `3` | BaseNoid の Bluetooth MAC アドレスを表示する |
| `4` | 設定モードを終了する |
| `5` | サーボ PID ゲインの調整 |

### サーボ PID ゲインの調整

`gain>` というプロンプトにコマンドを入力します．値の範囲は 0〜254 で，`-` を指定するとその値は変更しません．

| コマンド | 内容 |
| --- | --- |
| `p` | 現在の設定を表示する |
| `r` | サーボに書き込まれている値を読み出す |
| `w <対象> <P> [D] [I]` | 歩行中のゲイン |
| `n <P> [D] [I]` | 歩行以外のゲイン（全サーボ共通） |
| `s <P>` | 遊脚が空中にある間の P ゲイン |
| `z <対象> <値>` | 不感帯 |
| `save` | フラッシュに保存する（次回起動時に読み込まれる） |
| `default` | ソースコードに書かれた値に戻す（保存はされない） |
| `erase` | フラッシュに保存した値を消去する |
| `h` | ヘルプを表示する |
| `q` | 終了する |

`<対象>` には，サーボ ID（例 : `31`）か，グループ名 `all` / `upper` / `leg` / `hip` / `knee` / `ankle` を指定します．

```
w leg 64 - -    脚のサーボすべての P ゲインを 64 にする（D，I はそのまま）
w 34 96         ID 34 のサーボの P ゲインを 96 にする
z all 4         全サーボの不感帯を 4 にする
```

変更は `save` を実行するまで保存されません．保存せずに電源を切ると，変更は失われます．
