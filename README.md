# BaseNoid Program
## What's BaseNoid Program?
本リポジトリは，[Sugi_kmmm](https://github.com/Sugi-kmmm)が開発した初学者向けヒューマノイドロボット開発プラットフォーム BaseNoidのサンプルプログラムです．
PlatformIO上で開発されており，歩行，しゃがみ，パンチをはじめとした複数動作が可能になっています．
